二、操作指南
----------------------------------------
【基础操作（Java版 默认键位）】
1. 移动类：
   - W / A / S / D：前后左右移动
   - 空格键：跳跃 / 在水中游泳上浮
   - Shift：潜行（不会从方块边缘掉落）
   - Ctrl / 双击W：疾跑
2. 视角与交互：
   - 鼠标移动：转动视角
   - 鼠标左键：破坏方块 / 攻击
   - 鼠标右键：放置方块 / 使用物品（开门、吃东西等）
   - 滚轮 / 数字键 1-9：切换快捷栏物品
3. 界面类：
   - E：打开背包 / 合成界面
   - Q：丢弃手中物品
   - F：切换左右手物品
   - F5：切换第一/第二/第三人称视角
   - Esc：暂停 / 打开设置菜单
4. 创造模式专属：
   - 双击空格：开启/关闭飞行
   - 飞行时空格上升、Shift 下降

【生存流程操作指引】
1. 第一步——撸树：用手长按左键破坏树木，收集原木。
2. 第二步——做工作台：按 E 打开背包，将原木放入合成格做成木板，4 块木板合成工作台。
3. 第三步——做工具：用木板+木棍合成木镐、木斧、木剑。
4. 第四步——挖矿升级：用木镐挖石头做石制工具，再逐步升级铁质、钻石工具。
5. 第五步——安家过夜：天黑前建造简易房屋或挖洞躲避，制作火把照明防止怪物生成。
6. 第六步——食物补给：击杀动物获取肉类，或种植小麦、胡萝卜维持饥饿值。

【进阶操作技巧】
- 合成查询：在配方书中可查看所有可合成物品。
- 熔炉冶炼：将铁矿石、生肉放入熔炉加热，获得铁锭与熟食。
- 床与重生点：用 3 块羊毛 + 3 块木板合成床，睡觉可跳过夜晚并设置重生点。
- 附魔台：用书+钻石+黑曜石搭建附魔台，为武器工具附加强力属性。

三、通关目标
----------------------------------------
《我的世界》生存模式的最终通关目标是：击败末影龙，解锁结局动画。

【通关主线流程】
1. 发展基础：制作工具、建造房屋、储备食物，度过前几夜。
2. 采集钻石：在 Y=-59 至 Y=16 层之间的洞穴或矿道挖掘钻石矿石（需铁镐以上）。
3. 制作下界传送门：用黑曜石搭建 4x5 门框（去掉中间），用打火石点燃，进入下界（地狱）。
4. 寻找要塞：在下界击杀烈焰人获得烈焰棒，在主世界击杀末影人获得末影珍珠，用烈焰粉+末影珍珠合成"末影之眼"，跟随末影之眼指引找到要塞。
5. 激活末地传送门：在要塞的传送门框架上放置 12 个末影之眼，开启通往末地的传送门。
6. 决战末影龙：进入末地后，先摧毁黑曜石柱顶端的末地水晶（它们会为龙回血），再攻击盘旋的末影龙，注意躲避龙息和末影人。
7. 击败末影龙后，拾取龙蛋、收集经验，可通过返回传送门观看结局动画（可用火把诱使掉落方式采集龙蛋留作纪念）。

【通关后的延伸目标（可选）】
- 击杀凋灵（Wither）：用灵魂沙+凋灵骷髅头召唤，击败后获得下界之星，可合成信标。
- 探索远古城市：深入深暗之域，挑战监守者（Warden），获取幽匿系列物品。
- 收集成就：完成全部进度（Advancements），如"探索的时光""为什么会变成这样呢"等。
- 建造伟业：发挥创造力，建造属于自己的宏伟建筑，这也是《我的世界》永无止境的终极玩法。

一、游戏概括
----------------------------------------
《我的世界》（Minecraft）是由瑞典游戏设计师马库斯·佩尔松（Notch）创作、Mojang Studios 开发的一款沙盒类独立游戏，被誉为史上最畅销的电子游戏之一。

【核心特点】
1. 开放世界：游戏世界由无数方块构成，地形随机生成，包含平原、森林、沙漠、雪山、海洋、洞穴等多种生态环境，理论上地图可无限延伸。
2. 自由创造：玩家可以采集任何方块、自由建造房屋、城堡、机械装置，甚至还原现实中的著名建筑。
3. 生存冒险：游戏包含生存模式，玩家需要管理饥饿值、生命值，抵御怪物袭击，逐步探索世界。
4. 合成系统：通过工作台和合成配方，玩家可以将原材料制作成工具、武器、盔甲、药水等数百种物品。
5. 多种模式：
   - 生存模式（Survival）：需要采集资源、维持生命，是游戏的主要玩法。
   - 创造模式（Creative）：拥有无限资源、可以飞行，专注自由建造。
   - 冒险模式（Adventure）：适合体验地图作者制作的闯关地图。
   - 极限模式（Hardcore）：生存模式的困难版，死亡后无法重生。

【游戏世界观】
玩家扮演一名置身于方块世界的角色，从一无所有开始，通过砍树、挖矿、种植、养殖、合成，一步步建立起自己的家园，并最终挑战世界中的终极 Boss——末影龙。
