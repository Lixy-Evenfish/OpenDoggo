========================================
          《原神》游戏介绍文档
========================================

一、背景故事
----------------------------------------
《原神》的故事发生在一个名为「提瓦特」的幻想大陆上。
在这片大陆上，七种元素力量（风、岩、雷、草、水、火、冰）
分别由七位神明掌管，他们被称为「七神」，各自守护着一座国家。

主角是一对来自异世界的旅行者兄妹，在降临提瓦特时被神秘
的神明分离。为了寻找失散的血亲，旅行者踏上了遍历七国的
旅途，途中结识了温柔的向导「派蒙」，以及各国形形色色的
伙伴与对手。

旅途中，旅行者逐渐卷入涉及「深渊」、古代文明「坎瑞亚」
的灭亡真相，以及天空岛神明秘密的巨大阴谋之中，提瓦特大
陆的历史谜团也随之层层揭开。

----------------------------------------
二、游戏玩法
----------------------------------------
1. 开放世界探索
   - 提瓦特大陆无缝开放，可自由攀爬、游泳、滑翔。
   - 地图上散布宝箱、解谜、秘境、传送锚点和七天神像，
     探索与解锁能持续获得资源奖励。

2. 元素战斗系统
   - 角色拥有不同元素属性与武器类型。
   - 不同元素之间可以触发「元素反应」，例如：
     火 + 草 = 燃烧，水 + 火 = 蒸发，雷 + 水 = 感电等，
     合理搭配队伍是战斗的核心策略。

3. 角色养成
   - 通过祈愿（抽卡）获取角色与武器。
   - 养成维度包括：等级、天赋、武器、圣遗物、命之座，
     深度培养可大幅提升战力。

4. 多人联机
   - 支持最多 4 人联机，可共同探索世界、挑战副本秘境
     或讨伐强大 Boss。

5. 版本活动与剧情
   - 每个版本更新带来新国家地图、主线/世界任务、
     限时活动与玩法小游戏，内容持续更新。

----------------------------------------
三、操作方式
----------------------------------------
【PC 端（键鼠）】
- 移动：W / A / S / D
- 冲刺 / 加速：Shift（按住）；闪避：冲刺瞬间有无敌帧
- 跳跃：空格键；攀爬中跳跃可向上跃
- 普通攻击：鼠标左键（连续点击形成连击）
- 重击：按住鼠标左键（消耗体力，威力更高）
- 元素战技（小技能）：E 键
- 元素爆发（大招）：Q 键（需充能满）
- 切换队伍角色：1 / 2 / 3 / 4 数字键
- 拾取 / 交互：F 键
- 元素视野：鼠标中键（长按），用于追踪与解谜
- 打开地图：M 键；打开背包：B 键

【手机端（触屏）】
- 左侧虚拟摇杆控制移动
- 右侧按钮区包含：攻击、冲刺、跳跃、元素战技、元素爆发
- 点击屏幕上的图标可切换角色、拾取物品
- 支持滑动手势进行快速冲刺与视角转动

【主机端（手柄）】
- 左摇杆移动，右摇杆控制视角
- X/方块键普通攻击，Y/三角键元素战技，
  B/圆圈键元素爆发，A/叉键跳跃
- 十字键 / 方向键切换队伍成员
- LT/L2 元素视野，RT/R2 交互拾取

----------------------------------------
总结：凭借宏大的世界观、自由的开放世界探索、深度的元素
策略战斗与跨平台数据互通，《原神》成为了全球范围内极具
影响力的一款开放世界冒险 RPG。
